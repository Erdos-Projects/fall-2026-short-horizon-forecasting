# Results

The saved results of the project's full-data run (all 112 stocks, 3,830 windows), shown in the
[main notebook](../notebooks/01_forecasting_and_trading.ipynb) and the [README](../README.md).

| Folder | What's in it |
|---|---|
| `figures/` | Charts, including the main figure (forecast accuracy vs trading value) |
| `metrics/` | Result tables: forecast accuracy, trading results, robustness checks and the comparison with the team's original notebook (`reproduction_check.csv`) |
| `splits/` | Which market windows were used for development and which were held out |
| `run_manifest.json`, `run_manifest_upgraded.json`, `*.log` | When and how the runs were done |
